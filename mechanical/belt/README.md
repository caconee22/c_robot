# 벨트 구동계 도면과 계산

2026-10-10 기준 기구 설계 기록이다. 이 폴더의 현재 STEP은 형상 검토용이며 제작 승인본이 아니다.

## 공통 조건

- HTD5M, 피치 5mm
- 20T 풀리 두 개
- 풀리 피치원 지름: 31.83099mm
- 벨트 폭: 15mm
- 아이들러: 608 계열, 내경 8mm, 외경 22mm, 폭 7mm
- 아이들러 축: M8 볼트
- 단순 표시용 벨트 두께: 1mm

같은 20T 풀리 두 개의 무아이들러 피치 길이는 다음과 같다.

```text
L = 2C + 20 * 5
  = 2C + 100mm
```

따라서 중심거리 79mm는 258mm, 중심거리 129mm는 358mm다. 실제 구매품은 각각 260mm와 360mm이며,
아이들러로 약 2mm의 경로 증가와 초기 장력을 만든다.

## 모터-전륜 260mm 구간

위 풀리 중심 기준으로 아래 값을 사용한다.

| 항목 | 값 |
|---|---:|
| 풀리 중심거리 | 79mm |
| 이론적 260mm 아이들러 중심 | 왼쪽 18.249mm, 아래 36mm |
| 기존 직선 피치선에서 아이들러 중심까지 | 2.334mm |
| Ø22 베어링의 기하학적 누름량 | 8.666mm |
| 추천 슬롯 | 폭 9mm, 전체 길이 16mm |
| 슬롯 중심 이동량 | 7mm |
| 슬롯 중심 범위 | 왼쪽 17~24mm |

`17mm` 방향은 아이들러를 풀리 중심선 쪽으로 넣어 장력을 증가시키고, `24mm` 방향은 바깥쪽으로 빼서
벨트 장착 여유를 만든다. 실제 벨트 공차와 풀리 형상 때문에 이론점 하나로 구멍을 고정하지 않는다.

## 파일

- `belt_260_corrected_18.249x36.dxf`: 이론적 260mm 위치의 1mm 단순 벨트 외형
- `belt_260_pitchline_check.dxf`: 길이 260mm 피치선만 분리한 확인용 도면
- `belt_requested_13x36_263.23mm.dxf`: 왼쪽 13mm, 아래 36mm 위치의 비교 도면
- `belt_260_layout.svg`: 두 위치 비교 그림
- `idler_slot_dimension.svg`: 베어링 중심, 누름량과 슬롯 치수 그림
- `idler_slot_M8_9x16.dxf`: 추천 M8 슬롯 외형
- `motor_front_belt_current_review.step`: 사용자가 만든 최신 검토본

왼쪽 13mm, 아래 36mm 위치는 피치선 기준 약 263.23mm를 요구하므로 260mm 벨트를 팽팽하게 설치할 수
없다. 아래 36mm를 유지할 때 이론점은 왼쪽 약 18.249mm다.

최신 STEP에서 직접 추출한 값은 다음과 같다.

- 풀리 축간거리 79mm
- 아이들러 중심: 가로 17.9255mm, 위 풀리에서 아래 35mm
- 풀리 쪽 입력 원: Ø31.183mm
- 단순 벨트 두 경계: 약 257.976mm와 264.259mm
- 단순 형상 중앙선: 약 261.117mm
- 올바른 Ø31.831mm 피치원으로 같은 중심을 재계산한 경로: 약 260.169mm

현재 STEP의 Ø31.183mm가 피치원을 뜻했다면 숫자 순서 오류이므로 Ø31.831mm로 고친다. 또한 Ø22
베어링의 표면은 R11이므로 실제 벨트 외형은 베어링 바깥쪽 R11~R12에 있어야 한다. 현재 R10~R11
형상은 베어링 안쪽으로 들어가므로 물리 간섭 검토용으로 사용하지 않는다.
