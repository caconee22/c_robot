## LED 변경
PC 시험은 경기용 4216개, 벤치 1026개, GUI 시험 모두 통과했습니다. 경기용과 벤치 펌웨어 빌드도 성공했습니다. 다만 벤치 시험을 마지막으로 돌린 뒤에는 코드를 고치지 않았고, 경기용 시험은 마지막 벤치 수정 전에 돌렸습니다(벤치 전용 코드만 바뀜). 보드에는 아직 올리지 않았습니다.

| LED | 의미 |
|---|---|
| 빨강 계속 | 비상정지 |
| 빨강·흰색 번갈아 | 고장 (모터, 부팅, 배터리) |
| 흰색 천천히 깜빡 | 준비 중, SW2 안 먹음 |
| 초록 천천히 깜빡 | 출발 대기 |
| 초록 계속 | 벤치 구동 중 |
| 노랑 깜빡 | 타워 찾는 중 |
| 노랑 계속 | 타워 잡음 |
| 보라 계속 | 공격 |
| 파랑 빠른 깜빡 | 파란 홈 탈출 |
| 빨강 빠른 깜빡 | 빨간 홈 탈출 |

- 표시는 16가지에서 **10가지**입니다. 앞서 9가지라고 했지만 바닥 색을 넣으면서 빨간 홈 탈출이 하나 늘었습니다.

- 제가 정한 것 두 가지:
  - 밀기 뒤 후진은 바닥 색이 없어서 **보라(공격)**에 넣었습니다.
  - LED 밝기를 32에서 96으로 올렸습니다.
- `SystemManager`는 LED 표시 코드만 바꿨고 안전 판단은 그대로입니다.
